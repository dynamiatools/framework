# Dynamia Movies — backend

Spring Boot 4 + DynamiaTools `26.10.1-SNAPSHOT`. See the [project README](../README.md) for the whole picture.

```bash
./mvnw spring-boot:run     # http://localhost:8484  (admin / adminadmin)
./mvnw test                # end to end tests: public API, security, reports, dashboard
```

| Package | Contents |
|---|---|
| `domain` | `Movie`, `Genre`, `Studio`, `Person`, `Credit`, `Review` and the enums |
| `providers` | Navigation: backoffice `catalog`, `insights`, and the hidden read-only `public` module |
| `seed` | `MovieDataLoader` (catalog from `data/movies.csv`) and `ReportsDataLoader` (10 reports) |
| `dashboard` | `LatestReviewsWidget`, a custom UI-agnostic dashboard widget |
| `listeners` | `MovieGenresListener` |
| `config` | The glue needed to run the Vue theme, security and reports in one single-tenant app (documented in each class) |

Descriptors live in `src/main/resources/META-INF/descriptors`: `*Crud`, `*Table`, `*Form` for the backoffice and
`*Json` / `MovieJsonForm` for the REST API (they decide which fields the public site receives).

`src/main/resources/static/insights/` is generated by `pnpm build:insights` in `../frontend` and is not committed.
